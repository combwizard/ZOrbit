# Code of conduct

ZOrbit is a small project run by one person. Everyone who takes part, in issues, pull requests or anywhere else the
project lives, is expected to be decent to each other.

- Be patient and polite, with newcomers most of all. Not everyone knows ZBrush, Python or GitHub well.
- Criticise the code, the docs or the idea, not the person.
- Assume good faith. A short or blunt message is usually just short.
- No harassment, insults, slurs, sexual content, or personal attacks, and no posting anyone's private details.
- Respect a "no" or a request to stop.

## Reporting

If someone breaks these rules, report it privately through the repository's
[**Report a vulnerability**](https://github.com/combwizard/zorbit/security/advisories/new) form (it is the only
private channel; write "Code of conduct" in the title), or use GitHub's **Report content** on the comment itself.
Reports are kept confidential.

The maintainer may edit or delete comments, close or lock threads, and block people who break these rules, as they
see fit. In plain cases a warning comes first.
