A radial brush menu for ZBrush

Features

Stay in the canvas.

Flick, release, or click.

Hold the hotkey and flick past a slot, or move toward it and release. Or tap the hotkey and click. A pick that arrives mid-stroke waits until you lift the pen.

More than brushes.

A slot can select a brush, press any ZBrush button, set a slider, flip a switch, run several of those in a row, or open another ring. Hover a submenu and one stroke reaches an item two rings deep.

Any key you like.

Q is only where it starts. Record a new hotkey in Studio by pressing it: a letter, a digit, F1 to F24 or punctuation, with any mix of Ctrl, Alt and Shift. Give every menu its own key and open them straight from the canvas.

By default ZBrush never sees the key, so its own shortcut for that key doesn’t fire as well. Switch that off per menu if you want both.

Edit it in Studio.

ZOrbit Studio shows a live preview of the real ring. Drag brushes in from a searchable library, record hotkeys, change colours, size and animation. Twelve open animations, from instant to a swirling spiral.

It starts and stops with ZBrush. Your menus live in plain JSON, so you can back them up, share them and keep them in version control.

Install

Four steps. Then press Q.

  1. 1

    Download the installer.

    From the Releases page.

  2. 2

    Run it.

    It installs for your user only and does not need administrator rights. It adds a Start menu shortcut called ZOrbit Studio.

  3. 3

    Restart ZBrush once.

    ZBrush reads the plugin path only when it starts.

  4. 4

    Open a canvas and press Q.

    Hover over the canvas and hold the hotkey. The ring appears around the cursor. Q is the default; change it, or add more menus with their own keys, in Studio.

ZBrush 2022 to 2025: after installing, open Studio, go to Settings > Older ZBrush, and click Install. Then restart that ZBrush.

Needs Windows 10 or 11 and the Microsoft Edge WebView2 runtime (part of Windows 11 and of up-to-date Windows 10).

SmartScreen

Windows says “Windows protected your PC”.

The installer is not code-signed yet. Certificates cost money every year, and this is a free project, so Windows shows that warning for any program it does not recognise. It does not mean Windows found a problem.

After More info. The outlined button is the one.

  1. 01

    Click through it

    Choose More info, then Run anyway. The installer does the rest, including the Start menu shortcut.

  2. 02

    Use the portable zip

    Unzip the portable zip, run ZOrbit.exe once, and add its bridge folder to ZBRUSH_PLUGIN_PATH. Then restart ZBrush. The first launch of that file can show the same warning.

  3. 03

    Build it yourself

    Build it from the source in the repository, if you would rather not run a binary you did not build.

Hold Q. Flick. Done.
