Features

Stay in the canvas.

Flick, release, or click.

Hold the hotkey and flick past a slot, or move toward it and release. Or tap the hotkey and click. A pick that arrives mid-stroke waits until you lift the pen.

More than brushes.

A slot can select a brush, press any ZBrush button, set a slider, flip a switch, run several of those in a row, or open another ring. Hover a submenu and one stroke reaches an item two rings deep.

Any key you like.

Q is only where it starts. Record a new hotkey in Studio by pressing it: a letter, a digit, F1 to F24 or punctuation, with any mix of Ctrl, Alt and Shift. Give every menu its own key and open them straight from the canvas.

By default ZBrush never sees the key, so its own shortcut for that key doesn’t fire as well. Switch that off per menu if you want both.

Edit it in Studio.

ZOrbit Studio shows a live preview of the real ring. Drag brushes in from a searchable library, record hotkeys, change colours, size and animation. Twelve open animations, from instant to a swirling spiral.

It starts and stops with ZBrush. Your menus live in plain JSON, so you can back them up, share them and keep them in version control.

The basics

What is ZOrbit?

A radial menu for ZBrush on Windows. Hold a hotkey over the canvas and a ring of your brushes and buttons appears around the cursor. Flick toward one, or move to it and let go, and ZBrush switches. You set up the rings in ZOrbit Studio.

Is it really free?

Yes. There is no licence key, no account, no trial and no expiry date, and you can use it on as many machines as you like. The Licence screen in Studio is a joke. You can hide it in Settings > Studio.

Can I use it for paid work?

Yes. The GPL lets you run the program for any purpose, and it does not cover what you sculpt with it.

Which versions of ZBrush and Windows does it work with?

ZBrush 2022 or newer, on 64-bit Windows 10 or 11. ZBrush 2026 and newer load the plugin the installer sets up. ZBrush 2022 to 2025 need one extra step in Studio, see older ZBrush.

Is there a Mac or Linux version?

No. ZOrbit relies on Windows to catch the hotkey and draw the ring, so it runs on Windows only.

Is ZOrbit running when ZBrush is closed?

No. ZBrush starts it through the plugin, and it quits a few seconds after ZBrush closes. While it runs it has an icon in the notification area with Open Studio, Reload menus, Open logs folder and Quit ZOrbit.

Is it made by Maxon?

No. ZOrbit is an independent project. It is not affiliated with or endorsed by Maxon. ZBrush is a trademark of Maxon.

Are the reviews real?

No. The heading says so. The people and their quotes are made up.

Install and updates

Do I need administrator rights?

Not for the installer. It installs for your user only. The one exception is the plugin for ZBrush 2022 to 2025 when that ZBrush lives under Program Files: Windows asks once while Studio copies the plugin in.

Where does it install, and what does it change?

It installs to %LOCALAPPDATA%\Programs\ZOrbit. It adds that folder’s bridge folder to your user ZBRUSH_PLUGIN_PATH variable, keeping any entries already there, and adds a Start menu shortcut called ZOrbit Studio. A desktop shortcut is offered but off unless you tick it.

Why do I have to restart ZBrush?

ZBrush reads ZBRUSH_PLUGIN_PATH only when it starts. Restart it once after installing and it loads the plugin, which starts ZOrbit. After that it starts with ZBrush on its own.

I use ZBrush 2022, 2023, 2024 or 2025. What is different?

Those versions have no Python API, so ZOrbit gives them a ZScript plugin with the same Zplugin > ZOrbit palette. Open Studio, go to Settings > Older ZBrush and click Install next to your version. If it is not listed, use Add a ZBrush folder. Then restart that ZBrush.

What is the WebView2 runtime, and do I need it?

Studio draws its window with Microsoft Edge WebView2. It is part of Windows 11 and of up-to-date Windows 10, so you most likely have it already. If not, get it from Microsoft.

Is there a portable version?

Yes. Unzip the portable zip, run ZOrbit.exe once, add the zip’s bridge folder to ZBRUSH_PLUGIN_PATH, then restart ZBrush. The first launch can show the same SmartScreen warning as the installer.

How do I update?

When Studio opens it asks GitHub whether there is a newer release. If there is, an orange dot and the new version number appear at the top. Click it, download the installer from the release page and run it over your install. It stops ZOrbit, replaces the program and leaves your menus alone. Then restart ZBrush.

On ZBrush 2022 to 2025, Settings > Older ZBrush then shows Update available. Click Update and restart that ZBrush.

Can I turn off the update check?

Yes. Switch off Settings > Studio > Check for updates. While it is off, no request is made.

How do I uninstall?

Open Windows Settings > Apps > Installed apps, find ZOrbit and choose Uninstall. Restart ZBrush afterwards so it lets go of the plugin. The uninstaller removes only its own entry from ZBRUSH_PLUGIN_PATH.

On ZBrush 2022 to 2025, remove the plugin first with Studio > Settings > Older ZBrush > Remove. If you forgot, delete ZOrbitBridge.zsc and the ZOrbitData folder from that ZBrush’s ZStartup\ZPlugs64.

Does uninstalling delete my menus?

No. Your menus and settings are in %APPDATA%\ZOrbit and your logs in %LOCALAPPDATA%\ZOrbit, outside the program folder. Delete those two folders if you want no trace left.

I used Radial Menu for ZBrush. Do my menus carry over?

Yes. ZOrbit is the same project under a new name. Run the new installer over the old install. It moves the program, removes the old shortcut and plugin path entry, and copies your menus and settings to %APPDATA%\ZOrbit on first start. The old data folders stay where they are, and you can delete them. In ZBrush 2026 and newer, an F9 you bound by hand to the old Apply has to be bound again on Zplugin > ZOrbit > Apply.

Using the ring

How do I pick something: flick, release or click?

All three work, with the same hotkey:

  • Release. Hold the hotkey, point at a slot and let go.
  • Flick. Move out past a slot’s outer edge and it is picked at once, without letting go.
  • Click. Tap the hotkey, which keeps the ring open, then click a slot.

A press shorter than 250 ms counts as a tap. You can change that in Settings, from 0 to 1000 ms.

Do I have to point right at the icon?

No. A slot is chosen by the direction of the cursor from the centre, so pointing toward it is enough. Inside the small dead zone in the middle nothing is picked. A slot answers to at most a quarter of the circle, so on a ring of one to three slots, pointing away from all of them picks nothing.

What if I pick in the middle of a stroke?

The pick waits until you lift the pen or release the mouse button, then ZBrush switches. The tool never changes halfway through a stroke, so a pick that feels a moment late is doing this on purpose.

How do I close the ring without picking anything?

Any of these:

  • Release the hotkey in the middle of the ring, after holding it past the tap time.
  • Press the hotkey again, or press Esc.
  • Right-click, or click the middle of the ring.
  • Wait. It closes by itself after 20 seconds, which you can change in Settings.

With flick switched off, clicking outside the ring cancels too.

Where does the ring appear? What about screen edges and several monitors?

Centred on your cursor, with slots laid out clockwise from the top. Near a screen edge it moves just enough to stay fully on screen. Its sizes scale for high-DPI screens automatically.

Does the ring take focus away from ZBrush?

No. The ring window never takes keyboard focus, so ZBrush stays the active window underneath it.

Does it work with a pen tablet?

The ring opens from a keyboard key, so you point with the pen as you would with a mouse. Picks made mid-stroke wait for the pen to lift, and after each pick ZOrbit nudges the cursor by zero pixels to wake ZBrush’s pen tracking.

Hotkeys

Can I use a key other than Q?

Yes. In Studio, click the hotkey field on the Menus screen and press the keys you want. Or type it into the menu file, for example "hotkey": "Alt+G". It applies as soon as you save, with no restart.

Which keys and modifiers can I use?

Any mix of Ctrl, Alt and Shift, with a letter, a digit, F1 to F24 or one of ` - = [ ] \ ; ' , . /. In the menu file you can also use space, tab, enter, backspace, insert, delete, home, end, pageup and pagedown. The Windows key is not allowed.

Can I have several menus, each on its own key?

Yes. Give each menu its own hotkey and open it straight from the canvas. Two menus cannot share a key: the second is reported as a problem and ignored. A menu with no hotkey works as a submenu.

Will ZBrush’s own shortcut for that key fire as well?

Not by default. A menu swallows its hotkey, so ZBrush never sees it. Switch off Swallow hotkey in that menu’s settings, or set "swallow": false, if you want the key to reach ZBrush too.

Does the hotkey do anything outside ZBrush?

No. It only works while ZBrush is the front window. Everywhere else the key behaves as normal. Keys sent by other programs, such as macro tools, are ignored as well.

Menus, submenus and fans

What can a slot do besides select a brush?

Each slot does one of these:

  • Select a brush (brush).
  • Press any ZBrush button by its interface path (press).
  • Set a slider or value to a number (set).
  • Flip a switch (toggle).
  • Run a list of those in order (steps).
  • Open another ring (menu).
How many slots can a ring have?

There is no hard limit, but rings work best with 4 to 12. Each slot gets an equal share of the circle, so a crowded ring leaves less room to aim.

How do I find the path of a ZBrush button?

Join the palette and button names with colons, as ZBrush shows them, for example Tool:Masking:Clear. Capitals do not matter, and Studio suggests common paths as you type. A path your ZBrush does not have shows up in bridge.log as “no such interface item”.

What can a steps slot contain?

Brush, press, set and toggle actions, run in order. Steps cannot open menus or hold more steps. The starter menus have a Fresh Start slot that clears the mask and then picks the Standard brush.

Can I use my own brushes?

Yes, if ZBrush has them loaded or ZOrbit can find the .zbp. It looks in your ZBrush install’s brush folders and your user ZStartup\BrushPresets folder, subfolders included, and skips folders whose names start with an underscore. Spaces and capitals in a brush name do not matter.

Can I give a slot its own label or icon?

Yes. label is the text under the slot. icon can be a brush name or the path to a .zbp or .png. Without one, a brush slot uses the brush’s own thumbnail and other slots show a round placeholder with short text.

How do submenus work?

Put a menu slot on a ring. Move onto it and the submenu opens at once, centred on that slot. If you are still holding the hotkey, one movement can go into the submenu and on to one of its items. Release in the middle of the submenu to keep it open and click instead.

Can I stop submenus opening on hover?

Yes. Switch off Open submenus on hover in Settings, or set "hover_submenus": false. Submenus then open when you release or click on them.

What is the difference between a submenu and a fan?

A plain submenu replaces the current ring with a new one. A fan opens in place: its items spread in an arc beyond its slot, and the ring you came from stays on screen. Switch on Fan out when opened from another menu in the submenu’s settings, or add "fan": true to it. The setting belongs to the submenu, so every slot that opens it fans.

How do I pick from a fan?

The same ways as on the ring: release over an item, click it, or flick past it. Release on the fan’s own slot to keep it open and click. Moving the cursor away from a fan closes it.

Can a fan open another fan?

Yes, up to three deep, and the earlier fans stay visible. Where there is no room for a fan by a screen edge, or it would lead back to a menu already open on the way, it opens as a ring instead.

A fan menu also has a hotkey. What happens when I press it?

It opens as a normal ring. Fanning only applies when the menu is opened from another menu.

What is in the starter menus?

Brushes on Q, with the submenus More Brushes, Tools (masking, symmetry, PolyFrame, LazyMouse and other switches) and SubDivide. They use only brushes that come with ZBrush, so they work on any install.

Looks and animation

Which open animations are there? Can I turn them off?

Twelve: smooth, bounce, pop, zoom, fade, drift, fancy, spiral, ripple, breath, mist and snappy. Snappy has no animation at all. Closing is always instant, so a pick never waits for an animation.

Can one menu have its own animation?

Yes. Choose one under Open animation in the menu’s settings, or add "animation": "spiral" to the menu. Menus without one use the ring-wide setting.

Can I make the ring bigger or smaller?

Yes, in Settings. Radius goes from 60 to 400 pixels (145 by default), slot size from 32 to 160 (72) and the dead zone in the middle from 10 to 120 (38).

Can I change the colours, or hide the names?

Yes. There are five colours: slot fill, accent, highlight, text and lines. Any you leave alone keep their default, and Reset all colours puts them back. To show icons only, set Labels to none.

Studio and your files

What does Studio do?

It edits your menus. The Menus screen has a live preview drawn by the same code as the real ring. The Library lets you search every brush ZBrush can load and drag them in. Settings covers size, animation, labels, colours, timing and the ZBrush bridge. Status shows whether ZBrush, the app and the bridge are running.

Does Studio need to stay open?

No. The ring is drawn by a separate small app that starts and stops with ZBrush and reads your menus itself. Close Studio once you have saved.

Do changes apply right away?

Yes. The app reads the file again as soon as it changes, new hotkeys included. There is no need to restart ZBrush.

Can I undo in Studio?

Yes. Ctrl+Z undoes, Ctrl+Y or Ctrl+Shift+Z redoes, and Revert goes back to what is saved on disk. Closing with unsaved changes shows what you would lose and asks first.

Where are my menus, and can I edit the file by hand?

They are in %APPDATA%\ZOrbit\radial.json, a plain JSON file. Edit it in any text editor and the app picks up the change within about half a second. If you then save in Studio, it notices the file changed on disk and asks whether to overwrite it or reload.

What happens if I break the JSON?

The app keeps using the last good version and logs the error. Studio opens a recovery screen with the error, its line and column, and three choices: Open folder, Restore backup and Start from defaults. The unreadable file is kept as radial.json.broken.

The file is valid, but something in it is wrong. Then what?

Studio shows a problems pill. Each entry says what is wrong in plain words and jumps to the menu, item or setting to fix. The app skips bad items and logs what it skipped, and out-of-range settings fall back to their defaults.

How do I back up my menus or keep them in version control?

Copy radial.json. Studio also keeps the version before your last save as radial.json.bak. The file is plain JSON with two-space indentation, so it diffs cleanly in git.

How do I share my menus with someone?

Send them radial.json to put in their %APPDATA%\ZOrbit. They need the same brushes, and any button paths must exist in their ZBrush. Icons that point at .png files on your disk do not travel with it. Studio has no import or export because the menus are that one file.

How do I go back to the starter menus?

Delete radial.json (or move it somewhere safe). The app or Studio writes a fresh one from the starter menus the next time it starts. Single settings have their own reset arrows in Settings.

Troubleshooting

I press Q and nothing happens.

Work down this list:

  1. Make sure ZBrush is the front window. The hotkey is ignored everywhere else.
  2. In ZBrush, open Zplugin > ZOrbit > Status. If the palette is missing, see the next question.
  3. If Status says the app is not running, press Start App, then read app_stderr.log and radiald.log.
  4. In Studio, look for the problems pill. A menu with no usable items or a duplicate hotkey does not open.
  5. Another program may grab the same key first. Try a different hotkey.
There is no Zplugin > ZOrbit in ZBrush.

ZBrush did not load the plugin. Restart ZBrush, then check that your user environment variable ZBRUSH_PLUGIN_PATH contains ZOrbit’s bridge folder. On ZBrush 2022 to 2025, install the plugin again from Studio > Settings > Older ZBrush and restart that ZBrush.

The ring opens, but picking does nothing.

Open Zplugin > ZOrbit > Status and check that the listener says verified. If not, bind the fallback key: Ctrl+Alt+click Zplugin > ZOrbit > Apply, press F9, then Preferences > Hotkeys > Store. bridge.log names every action and whether it worked.

On ZBrush 2022 to 2025 the ring opens, but picks do nothing.

Picks there arrive through the bridge key. Hover Zplugin > ZOrbit > Apply and check its hotkey matches the bridge key in Studio, F9 unless you changed it. If you bound a key by hand, press Preferences > Hotkeys > Store, or the binding is gone after a restart. If Settings > Older ZBrush says Update available, update the plugin. zscript_bridge.log shows what the last pick did.

A slot shows letters instead of a picture.

There is no thumbnail for it. For a brush, ZOrbit found no .zbp file. For other kinds of slot a round placeholder with short text is normal.

Studio does not open, or its window stays blank.

Studio needs the WebView2 runtime. Install or repair it, then read studio.log in %LOCALAPPDATA%\ZOrbit, which records how Studio started.

Where are the logs?

In %LOCALAPPDATA%\ZOrbit: radiald.log for the app, bridge.log for the ZBrush side, app_stderr.log for crashes at startup and studio.log for Studio. ZBrush 2022 to 2025 also write zscript_bridge.log. Studio’s Status screen and the notification-area icon both open the folder.

Where do I report a bug or ask for help?

On the issue tracker. Say which Windows and ZBrush you use, what you did, what you expected and what happened, and paste the last lines of radiald.log and bridge.log. The logs hold brush names and menu ids, so glance over them first.

Privacy, safety and licence

Why does Windows say “Windows protected your PC”?

The installer is not code-signed yet, and SmartScreen warns about any program it does not recognise. It does not mean Windows found a problem. Choose More info, then Run anyway. The install section has the other ways through.

Does ZOrbit send any data?

No. There is no account, no tracking and no telemetry. The only network request is Studio’s update check, which asks GitHub for the latest release and sends nothing about you or your menus. The app that draws the ring and the ZBrush plugin make no network requests. On your own PC, the app keeps a count of which brushes you pick in usage.json, and that file never leaves it.

Does it need an internet connection?

No. Everything works offline. If the update check cannot reach GitHub, Studio notes it in its log and carries on.

ZOrbit uses a keyboard hook. What does it see?

Windows needs a hook for ZOrbit to catch your hotkey before ZBrush does. The hook only compares each key press with your menu hotkeys. It does not record or store keys.

What can ZOrbit do inside ZBrush?

Only what is on your menus: select a brush, press a button, set a slider, flip a switch, or a list of those. It does them through ZBrush’s own commands, and radial.json is plain text, so you can read exactly what each slot does.

I would rather not run a binary I did not build.

Then build it from the source. All of it is in the repository. You need Windows, Python 3.12 and the packages in requirements-dev.txt, then run packaging\build.ps1.

What is the licence? Can I change ZOrbit?

The GNU GPL-3.0. You can study, change and share it. If you distribute a changed version, you publish its source under the same licence. Third-party parts and their licences are listed in THIRD_PARTY_NOTICES.md.

Can I contribute?

Yes. Fork the repository, make a focused change and open a pull request. CONTRIBUTING.md has the details.
